# 原型生成器 (Prototype Generator)

> 简单、高效的 AI 原型生成与管理工具

---

## 简介

本项目是一个结合了 AI 大模型的 Web 原型生成工具。它不仅能让 AI 生成代码，还提供了完整的**预览、编辑、PRD 撰写、研发交付**全流程支持。

本次工作台升级包括 **全新项目库首页**、**本地 / AI 统一评审**、**PRD 插图与拖拽缩放**、**视觉预设与主动覆盖**、**真实交互热区提示**，以及 **纯净 / 研发两种交付版本**。完整亮点和升级方式见 [2026.10 更新说明](releases/2026-10-11.md)。既有 HTML PPT、团队协作和外部 AI 生成能力继续保留。

## 快速入门

### 启动项目
双击根目录下的 `启动项目.bat` 即可启动服务器，默认地址 `http://localhost:8080/src/`。

### 核心功能
*   **AI 生成**：输入描述，生成 HTML 原型。
*   **HTML PPT**：支持 PPTX 解析、原始配图回填、参考图辅助、概览小图和全屏播放。
*   **视觉设置**：138 份视觉风格，组件语言随风格，主题模式和自定义配色按主动修改覆盖。
*   **外部 AI 生成**：支持「仅复制完整prompt（1-2页面）」和「AI IDE 项目包（多页面）」两种模式。
*   **预览器**：本地 / AI 共用预览、微调、标注，支持 Web / App 切换与真机外壳开关。
*   **PRD 撰写**：所见即所得 Markdown、表格、文字配色、图片插入与拖拽缩放、自动保存。
*   **微调模式**：所见即所得的元素选择与 AI 修改。
*   **团队协作**：支持账号登录、团队创建 / 加入、项目分享到团队。
*   **研发交付**：纯净版 / 研发版下载与 GitHub Pages 发布共用入口，研发版包含导航、PRD、图片和序号。
