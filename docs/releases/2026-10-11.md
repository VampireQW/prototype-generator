# 2026.10 工作台升级

这次更新更聚焦 Codex、Claude Code 等本地 Agent 的协作：先把页面需求、参考图和视觉要求组织成结构化资料，交给 Agent 制作原型，再接入工作台完成交互评审、PRD 标注和研发交付。第三方 API 生成方式仍然保留，本地 HTML 原型与 AI 项目使用相同的评审和交付能力。

## 更新亮点

### 1. 全新项目库首页

- 全屏项目列表，紧凑的本地 / AI 来源切换与新建入口，支持浅色和深色主题。
- 冷白画布、石墨导航与冰青强调，统一卡片、按钮、菜单、弹窗和交互反馈。
- 按名称 / 路径搜索、状态筛选、最近创建排序；返回列表保留搜索和创建草稿。
- 本地与 AI 项目卡片统一为图标操作，更多操作集中在菜单中。
- 支持真实项目封面和本机缓存；App 封面居中展示，无法渲染时使用名称封面。
- 补齐加载、空结果、错误重试、目录失效、键盘菜单与弹窗焦点管理；布局适配桌面和手机。

### 2. 更清晰的新建与设计设置

- 独立创建页，压缩顶部和表单空间，增加项目名称，留空自动命名。
- 视觉风格统一带出组件语言和默认配色，主题模式支持跟随风格 / 浅色 / 深色。
- 138 份视觉风格可选；主色和辅色按需自定义，顶部色样展示最终生效配色。
- 主动覆盖仅影响修改的字段，未修改的设置继续继承预设。
- 内置 AI、复制完整 Prompt、外部 AI IDE 项目包共用同一套优先级，减少界面与实际生成规则不一致的问题。

### 3. 本地与 AI 共用评审工作台

- 预览、微调、标注三个模式统一；页面 / 状态导航、PRD、序号定位与修改任务共用。
- 兼容多 HTML 页面及同文件状态切换，提供稳定元素锚点与 Bridge 通信约定。
- App 原型支持真机外壳开关；切换外壳保留输入和当前业务状态，Web 视图隐藏该开关。
- AI 生成及两条外部 AI 生成路径同步工作台协议，单文件 / 多文件组织与 Prompt 保持一致。

### 4. PRD 图片与所见即所得编辑

- 页面需求、右侧标注明细和序号浮窗均支持 Markdown、表格、文字颜色与自动保存。
- 图片支持文件选择、截图粘贴与拖放；PNG / JPEG / GIF / WebP，单张最大 10 MB。
- 单击图片后拖动右下角等比调整大小，实时显示尺寸；支持撤销 / 重做、键盘调整及取消拖动。
- 图片尺寸随正文保存，重新编辑和导出后继续保留。
- 格式工具条位于编辑框外侧，支持拖动与归位，不挤占正文，也不留下工具条占位空白。
- 图片写入项目相对资源目录，研发版下载与 GitHub Pages 发布包含图片资源。

### 5. 更明确的标注与交互提示

- 文字颜色和序号颜色分别使用专用色板，序号默认蓝色置于首位，颜色随标注保存。
- 重新绑定和删除等操作精简排布，右侧标注之间使用较浅虚线分隔。
- 点击原型空白处时，真实交互区域短暂显示半透明橙色呼吸高亮，约 2 秒后隐藏。
- 静态按钮、禁用或隐藏控件不作为可点击依据；高亮层穿透点击，保留业务操作。
- 交互热区提示与隐藏序号的引导使用不同表现，减少误解。

### 6. 发布与研发交付统一

- 本地与 AI 共用发布 / 导出入口，只保留纯净版和研发版，移除内嵌版选项。
- 下载与 Pages 发布采用相同版本选择；研发版携带页面 / 状态导航、PRD、图片、序号及热区提示。
- 研发版支持 HTTP、GitHub Pages 子路径和 `file://` 阅读；原型自身的联网业务仍遵循其原有依赖。
- GitHub 配置、发布和下载按钮保持单行，精简菜单层级与间距。
- 区分 Token 未配置与已有凭据不可解密；Windows 凭据由保存时的同一账户读取，避免把启动账户不同误判为 Token 丢失。

### 7. 本地运行与维护完善

- 首页样式、图标及 PRD 编辑器运行资源随仓库提供，补齐此前被忽略规则遗漏的 Markdown 依赖。
- 核心服务、封面和开发测试依赖分开记录，日常启动无需前端构建。
- 封面在独立浏览器上下文离线渲染，限制队列、并发与超时，沿用项目访问权限。
- PRD 元数据采用 revision / CAS 保存；新增草稿导入脚本，可将结构化 PRD 导入标注工作台。
- 禁止 Windows 同端口重复监听，图片上传遇到旧服务时提供明确的重启指引。

### 8. 可安装的 Agent 协作 skill 与界面截图

- 提供 `agent-skills/prototype-flow/`，指导本地 Agent 接入原型、组织页面 PRD / 元素标注并通过导入工具落库，以及执行工作台修改任务。
- skill 使用可配置的工具仓库与原型项目路径，附带按任务读取的协议；不包含个人项目、配置或密钥，也不约束原型视觉风格。
- 补充 [Codex / Claude Code 安装与使用指南](../agent-skill.md)，明确 PRD 元数据导入与首页目录登记的区别。
- README 展示新建项目、PRD 标注、微调和手机外壳预览四张真实界面截图，使用隔离演示数据。

## 升级方式

1. 关闭旧的原型生成器服务，更新源码，保留本机配置和项目目录。
2. 推荐 Python 3.11+，安装核心依赖：

   ```bash
   python -m pip install -r requirements.txt
   ```

3. 需要真实项目封面时，安装可选依赖和 Chromium：

   ```bash
   python -m pip install -r requirements-preview.txt
   python -m playwright install chromium
   ```

4. 通过 `启动项目.bat` 或 `python server.py` 启动，以原保存凭据的 Windows 账户运行，并刷新浏览器。
5. 既有 GitHub Pages 评审站需重新发布，才会包含新的图片尺寸、标注和热区功能。

没有安装封面依赖时使用名称封面，核心管理、编辑与交付功能仍可使用。需要外部网络初始化的原型可能无法生成离线封面。
