# 更新日志 (Changelog)

## 2026-10-16
### 右侧 PRD 编辑工具条默认位置
- 页面需求进入编辑时，工具条默认浮在当前正文上方；标注进入编辑时，定位在该条序号栏上方。工具保持单行，右端对齐编辑区 / 序号栏，空间不足时向左延伸，不折行、不使用横向滚动。
- 接近侧栏顶部时，仅在进入编辑的一刻调整阅读区滚动，露出工具条；保持正文布局与高度，不添加占位，手动拖动及归位保留。原型上的标注浮卡继续使用外框避让。

### 隐藏标注的展开引导与序号联动
- 修复只有正文说明、缺少运行时条件关联时不显示展开入口的问题：目标和祖先的 data-proto-reveal-by 声明在运行时直接解析，兼容没有 conditions 的旧锚点；多层隐藏先引导到可见外层入口。
- 点击右侧序号及展开引导共用异步显现路径，依次切换 Tab、打开子视图，等待渲染后再定位；并发请求合并，同一入口只执行一次，避免重复开关、重置草稿或误弹新建标注。
- 工作台与研发 / Pages 评审共用新逻辑，过期或无效入口不盲点确认 / 清空，失败如实反馈；skill 补充隐藏目标的接入及验收要求。

### 本期 PRD 逐条溯源与误注清理
- 草稿升级为版本 3：本期需求须引用用户原文并说明改造前后差异，背景 / 目标与标注 items 每条关联需求，工具统一生成 Markdown；旧版整段正文拒绝导入，元数据版本仍为 2，既有 PRD 不自动修改。
- 收紧协作 skill：重新整理不等于补全整页，撤销本期改造后仍原样成立的旧功能不提交，容器不能夹带旧规则；仅选择适用小节，不凑齐五项。
- 明确授权后可用 removals 按页面 / 状态和标注 ID 定点清理误注，保留已确认内容并记录删除定位；修订使用 update，背景 / 目标用 --replace-doc，保护人工删除结果和其他历史。
- 导入报告增加本期需求、改造差异、逐条 contentRefs 与清理结果；发布目录、本地 Qoder skill 及 AI / 外部 Agent 提示同步新协议。

### 项目改名与发布序号跟随
- 项目名编辑图标改为鼠标悬浮标题区域时显示；键盘聚焦、改名弹层打开时保持显示，触屏保留常显入口，显隐不引起标题位移。
- 左侧顶部显示项目名称，支持在标题旁修改；本地文件夹按输入名称同步更名，保持项目 ID、页面关系、PRD 与已发布地址。AI 项目同步首页、记录及归属 / 团队分享；重名、非法目录名和旧 revision 拒绝执行，写入失败恢复原目录与元数据。
- 页面列表缩小行内留白、状态行和端分组间距，保留触屏操作尺寸；演示入口与研发导出共用紧凑导航并显示项目名。
- 修复研发导出 / Pages 原型内嵌滚动区滚动时序号固定的问题：捕获嵌套滚动，逐帧更新锚点位置；滚出可见区域自动隐藏，滚回恢复。已有静态发布需要重新发布生效。

### PRD 结构、落库定位与精确点击提示
- 页面需求按需补充背景和目标，不再为每次导入补写“研发实现”；新增 / 更新标注按页面显示、数据流转、业务规则、交互说明、异常情况中适用的小节，用 Markdown 标题、列表或表格组织，导入拒绝大段无结构正文、空小节和页面研发实现标题，保留历史 PRD。
- 旧 AI 项目接入不再把布局、功能、交互输入自动拼成页面需求；仅显式背景与目标可补充，已有正文与旧 PRD 文件迁移保持原样。
- 导入与接入报告增加项目名称、页面名称和直达标注链接，工作台支持 page / state / mode 参数，切页与状态变化同步地址；Agent 完成回复必须说明落在哪个项目、页面 / 状态并附链接。
- hotspots 改为独立显式清单，省略即不提示；运行时仅精确匹配控件 ID，容器不再扩散到内部旧交互。预览、研发导出和 Pages 共用新规则。

## 2026-10-15
### 页面三级树与拖动归类
- 左侧页面支持最多三级父子结构、折叠 / 展开和当前页面祖先自动展开；拖到中部移入，上下边缘同级排序，端标题 / 顶层页面边缘解除父级。整棵子树跨端移动，拖动提供目标提示、插入线、无效原因与悬停展开，Esc 取消，保存失败恢复。
- 键盘 Alt + ↑ / ↓ 同级排序，Alt + → 移入前一同级，Alt + ← 提升一级；后端拒绝循环、跨端父子和超过三级的数据，保存 / 导出 / Pages / 独立演示共用层级。
- 回收父页面保留子页面显示与原关系；彻底删除仅删除指定页面，将子页面提升一级。接入 skill 支持 parentId / parentFile 并保留平台手动整理结果。

### 左侧导航表面与画布分离
- 左侧页面导航、端筛选和回收站底色统一使用右侧 PRD 的面板底色，浅深主题同步；右边缘保留清晰的 1px 分隔线，与手机 / 平板外壳外的画布区分。
- 导航收起时移除分隔线，保持画布完整可用宽度。

### 页面回收站与本地文件删除
- 左侧导航增加回收站入口，页面设置支持移入回收站；恢复保留原顺序、状态、PRD、标注和任务，当前页面移走后自动切换，项目可为空。
- 回收站支持逐页彻底删除，经文件名确认后删除实际 HTML 和该页关联数据，维护导航清单；保留共用资源，操作失败回滚文件与元数据，过期 revision 拒绝执行。
- 回收站页面不出现在预览、演示导航及研发 / 纯净导出中，关联 PRD 不随导出；自动扫描和 PRD 导入不擅自恢复。

### Pad 显示类型与平板外壳
- 视图、页面设置和新增端分类支持独立 Pad 类型；横向 1180 × 820 画布配平板外壳，随预览空间缩放，外壳可关闭，切换不重载原型。
- 页面 / 端 / 状态清单、Agent 接入协议与生成提示、独立演示入口及研发导出 / Pages 同步支持 pad，避免把平板按手机或 Web 呈现。
- 缩放后微调点选 / 框选、标注浮卡、颜色菜单和 Markdown 工具条避让按实际缩放换算坐标。

### PRD 与交互提示按本次需求限定
- 协作 skill、AI / 外部 Agent 交付提示统一默认增量范围，草稿升级为版本 2，声明基准 revision、本次需求与关联元素；范围外内容和过期草稿拒绝导入。
- 点击提示读取页面状态的 interactionHints，默认只提示本次目标中的真实交互；未声明范围的旧页面不再整页提示，全量 PRD 与整页提示分别显式开启。预览与研发导出 / Pages 共用范围。
- 工作台保留标注删除定位，导入结合历史归档防止补回；显式 update 保留现有身份与编号，恢复已删除内容需明确 restore，不覆盖已确认内容。

### 模型管理暗色主题修正
- 移除右侧表单和列表选中项的浅色半透明底，改用主题表面、边缘与编辑焦点色。
- 当前模型、多模态标签、输入框、必填标识和按钮悬浮状态同步浅深主题，保持文字与控件清晰。

### 模式图标与发布按钮对比度

- 修正通用模式按钮样式覆盖发布按钮的文字色问题，发布按钮默认、悬浮及键盘焦点状态均保持清晰的黑白对比。
