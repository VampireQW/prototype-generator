# 更新日志 (Changelog)

## 2026-10-23
### 推送前发布流程回归修正
- 取消发布先校验本地项目访问权限，再读取 GitHub 配置，跨用户访问不会被配置缺失的提示抢先返回。
- 更新旧发布测试，按当前 Git 提交方式验证嵌套资源、远端清单与本地发布状态同步；窄屏右栏工具条测试沿用已确定的单行左延伸规则，浮窗仍要求完整位于视口内。

### 展开路径详情压缩布局
- 展开方式改为原生单选项，直接选择自动识别、手动路径或复用其他标注，切换复用 / 自动继续即时保存；空的手动路径明确提示添加后生效。
- 识别 / 手动路径说明合并为紧凑状态行，保留必要异常与来源信息；点选入口、测试展开及保存状态放在同一操作行，收紧辅助说明。

### 展开联动单击响应与识别结果整理
- 修复原型业务 DOM 变化时整块重建右侧面板，导致设置、返回、删除在按下与松开之间被撤换而丢失点击。后台刷新比较实际状态，无变化保留控件；鼠标 / 键盘操作及输入期间延后刷新，同一视图保留滚动位置。
- 列表显示需处理 / 自动 / 手动 / 当前无需的数量，每条标注区分需补充入口、目标未找到、自动识别、手动配置与当前无需展开，并展示真实路径和共用来源；已确认标注可以查看，修改继续受保护。
- 自动识别结果独立展示具体步骤、当前目标显隐和入口可用状态。只读检查声明关系、原生折叠、ARIA 关系及同一区域的共用路径，弹窗打开时也可查看；冲突、失效和禁用入口明确提示，不通过业务点击试探或改写原项目。

### 展开联动改为即时保存，并识别同一弹窗的共用路径
- 移除「保存关联」「使用此路径」，添加步骤、删除、排序和选择复用后立即沿用 CAS 保存；下拉框显示实际生效方式，不再默认选中一个尚未采用的来源。
- 自动模式可识别当前页 / 状态中同一隐藏容器内唯一明确的手动展开路径，无需为每条标注重复配置；显示自动共用来源及实际步骤。不同容器、路径冲突、入口缺失 / 不可用时不推断，已有显式关系和自身路径优先。
- 工作台与研发导出 / Pages 同步提供当前作用域的标注上下文；自动共用不写回标注，多条标注异步展开同一容器时合并等待，防止重复开关。保存失败明确显示尚未生效，保留修改供重试或放弃。

### 多条标注共用展开入口与路径复用
- 修复点选展开入口时，已有黄色引导覆盖业务按钮、导致第二条标注点不到相同入口的问题。点选期间让平台自有图层穿透，仍拦截业务点击；选择完成、取消、切页时清理临时样式。
- 展开路径设置增加「复用已有展开路径」，可从当前页 / 状态的其他标注复制步骤，先测试、再保存；每条标注保留独立锚点、正文、序号及确认状态，不自动改写来源或其他标注。
- 同一入口的同类路径继续汇总为一个黄色引导，显示关联标注总数。补充自动容器声明可被多个内部标注共同识别的回归，验证共享入口不会重复开关已显现内容。

### 左侧导入页面支持重新导入替换
- 截图页和已导入 HTML 页的「页面设置」增加对应的重新导入入口，可从左侧直接替换任意导入页，无需先切换到该页；普通原型页不显示入口。
- 截图复用原有替换接口；HTML 新增专用替换操作，保留页面 ID、名称、导航、层级、优先级、进度、状态、PRD、标注及热区配置，只更新本页入口和配套资源。
- HTML 替换按 revision 校验并备份原文件；清理旧资源，失败恢复被覆盖 / 移除文件并清除本次新文件，拒绝覆盖目录内未登记文件。窗口失败保留所选内容供重试，成功刷新原型；布局或控件结构变化需检查定位。

### 修复发布后序号需要多次点击才选中
- 定位重排原先清空并重建所有序号；业务 DOM 更新、滚动或尺寸变化若发生在鼠标按下与松开之间，会断开点击目标，导致浏览器丢失本次 click。
- 序号按稳定标注 ID 复用按钮，仅更新位置、编号、正文回调和选中状态，不移动已存在节点；只有目标隐藏、失锚、切换状态或移除标注时清理对应按钮，继续保持弹窗关闭后的即时隐藏。
- 增加按下期间连续重排、复用后编号 / 正文更新及目标隐藏的回归；研发导出和 Pages 共用修复，旧产物需要重新导出 / 发布。

### 恢复发布 / 导出标注的持续选中高亮
- 原型序号增加选中外环，右栏标注序号栏与编号同步高亮；两侧点击按稳定标注 ID 同步当前选中项，保留自定义序号颜色。
- 序号和右栏列表重建时恢复选中状态，不再只依赖 1.2 秒 flash；PRD 开合、滚动及尺寸重排不清除选择，切换页面 / 状态或移除标注时清理选择。
- 评审桥新增 selection / select 同步，初始化保留选择，仍校验消息来源；不写回项目元数据，研发导出与 Pages 共用并通过内容版本刷新脚本。

## 2026-10-22
### 修复重新发布后原型 iframe 继续读取旧脚本缓存
- 实测已发布站点的外层页面已更新，而无查询参数的原型 HTML 仍命中旧版本；新地址读取到的脚本才包含浮窗拖动与显隐监听，造成修复发布后仍出现序号残留。
- 研发构建对最终原型 HTML（含内嵌运行时）生成 SHA-256 内容版本，评审 iframe 与「交互原型」链接使用同一版本地址；只更新标注脚本、PRD revision 不变时也会改变版本。
- 版本不写入项目元数据，旧清单保持兼容，同页状态切换不重载 iframe；增加最终内容校验、运行时升级、链接配套与导航回归。

### 研发导出浮窗支持拖动，修复弹窗关闭后的序号残留
- 阅读浮窗顶部增加移动握把，支持鼠标 / 触屏拖动及方向键微调；限制在视口内，Esc、指针取消或失焦可恢复本次移动前位置，保留正文滚动与左右边缘调宽。
- 导出标注层改用 DOM 显隐 / 内容变动监听并过滤自有图层，移除 HTML 字符数变化检测；关闭弹窗与显示入口造成相同字符数时，也会立即重排序号。
- 标注目标隐藏 / 移除时一并关闭对应浮窗，重新显示目标后恢复序号；共享研发导出 / Pages 脚本，旧发布与旧下载包需要重新发布 / 导出。

### 修复拖动 / 重新绑定后序号消失
- 相对落点按控件实际边框尺寸还原，与创建比例时使用的坐标一致；tooltip、绝对定位子节点或长文案造成的 scrollWidth / scrollHeight 溢出不再把序号推到控件外并隐藏。
- 保留既有锚点与 placement 格式，旧记录刷新即可恢复正确显示；工作台、研发导出与 Pages 共用同一定位逻辑，已发布版本需重新发布。
- 增加溢出尺寸、缩放 / 滚动、旧绝对落点和移动 / 重绑后保留正文、身份及数量的回归；浏览器隔离副本验证拖动、重绑确认和刷新持久化。

### prototype-flow 增加历史业务数据处理确认
- 功能改造涉及旧记录字段、状态、默认值、关联或统计口径时，与范围确认一起提供影响说明、可行选项、推荐方案和理由；无影响或已有明确决定时不重复询问。
- 用户确认后将本期处理边界写入适用标注小节和 brief；未知策略只列待确认，区分业务数据与平台 PRD 历史，明确记录规则不授权实际迁移 / 重算 / 修改业务库。

### prototype-flow 增加落库前范围确认
- 尚无已确认具体清单时，先展示“仅本次改动（推荐）／当前页面完整业务需求／自定义范围”，前两个选项简列实际业务项，并说明页面 / 状态、排除项、背景目标和点击提示处理；等待真实用户答复。
- 明确授权同一具体范围后不重复询问，扩项仅确认变化部分；记录范围与真实确认依据，草稿和 dry-run 报告逐项核对，区分新增 / 更新 / 保留 / 拟删除。
- 保留版本 3 工具协议、既有 PRD 和人工删除保护，说明当前结构校验的语义边界；仓库发布版与本地 Qoder 技能副本同步。

### 手动文案修改统一兼容动态表格与列表
- 动态节点不再强制要求行 ID：优先显式稳定键，其次用未编辑的行 / 条目内容识别唯一对象；表格列按完整分组表头定位，支持 rowspan / colspan。无 ID 列表可使用标题等相邻内容，无 ID 的短按钮 / 标签可使用唯一原文定位；容器缺少 ID 时可回退到页面 body。
- 排序、筛选、重绘后按语义重新寻找目标，不把消失行的修改套到下一行；相同数值的其他行保留。手动改名保留原绑定，已修改的行标识用原文记录匹配，仍只操作文本节点。
- 工作台加载时在响应副本中更新已有内嵌文案运行代码，保留源文件、正文及修改记录；保存时再写入当前运行代码，导出仍可独立运行。无法唯一识别的重复条目保留保护。
- 以班级对比页面的隔离副本验证无行 ID 的单元格保存、筛选恢复、刷新、再次编辑和撤销；配套覆盖无 ID 列表、无 ID 按钮、多级表头、列移动、行标识改名及旧运行代码升级。

### 新启动实例自动替换旧服务
- 双击 `启动项目.bat` 或运行 `server.py` 时，先尝试独占监听；端口已占用时核对本目录实例记录和运行身份，再通过本机鉴权交接接口通知旧服务退出并接替，不按端口查杀进程。
- 保存、发布等请求仍在执行或后台生成未结束时等待完成，最长 330 秒；超时保留旧任务。交接开始后拒绝新操作，防止退出期间再写入。异步失败记录落盘完成后才标记任务结束。
- 同目录、同端口的连续启动使用系统文件锁串行处理；退出清理核对实例身份，避免旧实例删除新实例的记录。交接密钥不进入 API 响应，实例 / 锁文件禁止通过静态 HTTP 访问。
- 浏览器改为新服务就绪后打开，并跟随实际配置端口；正常退出不再 `pause` 留住旧启动窗口，启动失败仍保留错误提示。增加实例替换、忙碌等待、超时、跨目录保护、凭据及锁回归。

### 修复脚本生成标签无法手动修改
- 学生答题页的胶囊标签由数据和 JavaScript 生成，源码中对应容器为空；旧逻辑仅匹配静态文本节点，导致提示“无法在源文件中精确定位”。新增以静态容器和动态控件稳定键定位的文案修改，支持 `data-q` / `data-key` / `id` 等唯一标识。
- 动态文案按控件保存为 HTML 内独立记录与内嵌重放脚本，不全局替换数据字符串。即时保存后、点击重绘及刷新保持修改，保留点击行为、图标和其他控件文案；纯净 / 研发导出及 Pages 无需本机服务即可保留。
- 沿用文件版本校验、预览取消与原字节撤销；目标不唯一、缺少稳定键、框架绑定或原文冲突仍拒绝覆盖。隔离副本验证保存、点击重绘、刷新与撤销，未改业务项目的文案和 PRD。

### 统一添加页面入口与 HTML 导入
- 左侧原截图图标替换为「＋ 添加页面」文字按钮，与页面导航同一行右对齐；下拉菜单提供「截图页面 / 导入 HTML」，浅深主题、方向键和 Esc 统一处理。
- HTML 支持单个文件、粘贴源码或选择带静态资源的页面文件夹；多个 HTML 可选择入口，只导入选定 HTML 与配套资源，沿用页面名称、外壳、端分类及父级设置。导入后保留源码和原有交互，支持标注、热区、层级与页面跟踪。
- 文件进入独立目录，保留相对路径，不覆盖已有页面或生成 PRD。新增本机同源导入接口，校验 revision、路径、文件类型及体积，写入失败回滚，中断保留恢复记录。
- 回收站恢复保留资源，永久删除清理该页专属资源；研发版、纯净版及 Pages 导出携带资源，排除回收站内容。HTML 使用 UTF-8，入口最大 5 MB，资源单文件最大 10 MB、合计 30 MB，最多 300 个文件。
