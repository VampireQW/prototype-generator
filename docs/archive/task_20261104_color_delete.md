# 删除彩色文字后残留 span

日期：2026-11-04。

## 根因与实现

用真实 Vditor IR 编辑器复现整段彩色文字删除：浏览器会删除 .proto-md-color 展示壳及起始 HTML 标记，却留下闭标记；Vditor 将其当作普通内联 HTML 写回 Markdown。既有 EMPTY_COLOR 正则只匹配完整的空颜色标签对，不能清理该孤立闭标签。事件采样表明，input 捕获阶段仍能识别编辑器装饰节点，后续 Vditor 重渲后已失去这些身份信息。

在 beforeinput 保存编辑器自己生成的有效颜色标签对和展示壳引用；input 捕获阶段先清除已删除文字的边界，或补回部分删除后剩余文字的边界，然后继续原生 Vditor 输入处理。没有 setValue 重建全文，没有全局替换 span 字符串，也没有重写存量 PRD。脚本引用增加版本以更新浏览器缓存。

## 验证记录

修改前的六组删除复现失败，其中跨起 / 闭标记和普通文本选区均真实生成孤立 </span>；整段选区的测试随后改为用户实际拖选产生的文本节点边界。修复后六组 Backspace / Delete 已通过；继续增加部分删除、双颜色跨选、替换、相邻颜色保留、三种编辑区域 / 浅暗主题、原生撤销与工具栏重做、自动保存、阅读态与重新进入编辑、内联 / 围栏代码标签保留等回归。

撤销测试等待同次输入真正自动保存后再操作，遵循编辑器原有延迟入栈机制；对照确认无需修改原生撤销基线，最终未保留该试验改动。所有用例只使用隔离服务器与固定测试内容，不访问真实项目或 GitHub。
