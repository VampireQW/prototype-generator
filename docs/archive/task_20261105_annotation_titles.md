# 标注标题、序号外观与多级列表

## 范围

标注首行增加独立纯文本标题并自动加粗；仅为原型页气泡提供项目级颜色 / 大小设置。右侧正文、标题字体和小编号不提供全局改色 / 字号。现有业务 PRD 不迁移、不改写。

## 实现

- 可选 title 字段复用串行保存和版本冲突处理，确认标注只读，空标题移除，失败保留并可重试。
- 可选 project.pinStyle 通过共享外观模块、工作台宿主和评审桥生效，复用实际气泡几何；颜色覆盖可以撤销，原单条颜色保留。
- 编辑器与阅读 / 评审 / 浮窗统一多级编号；导出解析器修复列表层级压平，使用缩进栈保留父子列表和续行。
- 发布快照记录样式和标题变化并提供可定位的更新说明。

## 验证与对抗性自审

验证报告位于 tmp/note-titles/。合成项目覆盖标题保存 / 刷新 / 删除 / Esc、原始 HTML 作为纯文本、确认锁定、保存失败保留及重试、跨页外观、恢复原配色、右栏尺寸和锚点保持、编辑 / 阅读 / HTTP / file:// 列表层级。作者自审另检查元数据非法值、未知字段、样式撤销以及更新说明的正确分类；结果以最终测试报告为准。

整体回归 781 passed、1 skipped、1 deselected；后续空标题不显示占位、草稿保护与列表混排边界调整后，受影响范围 144 passed、1 deselected。实际服务的项目入口和加粗 / 无占位输入只读验证通过，元数据哈希未变。外观、正文和标题的实测细节分别保存在 browser-result.json、live-result.json 和测试 XML；实际服务继续运行，测试服务验收后停止。
