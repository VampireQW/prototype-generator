# 功能详解 (Feature Details)

## 首页升级（2026-10-10）

石墨顶栏、冷白画布和青色操作统一本地 / AI 项目库。项目卡片按需载入真实封面；后台渲染失败时保留项目名称卡片。搜索、筛选、数量与最新创建排序继续有效，刷新不清空原卡片。

常用操作统一为预览、发布 / 导出、更多；AI 编辑名称、复制、生成记录、团队分享和回收站，以及本地移出 / 删除进入更多菜单。菜单支持方向键与 Esc，弹窗支持焦点循环与返回。目录失效卡片可打开添加目录面板。连接中防止重复提交。

≤640px 单列，搜索全宽、筛选 / 添加 / 刷新同行。创建页、全局菜单和发布弹窗同步浅深主题。新外观不改变生成原型的风格配置。

## 视觉风格与配色（2026-10-05）

新建项目默认只显示「类型 / 视觉风格 / 主题模式」。视觉风格统一提供配色、字体与组件语言，删除独立组件选择。主题默认为「跟随风格」，也可指定浅色 / 深色；开启「自定义配色」才展开主色、辅色，关闭即恢复预设。顶部色样展示最终生效的主色、辅色、背景、表面、文字、控件边界。

AI 生成、复制 Prompt、外部 AI 项目包使用相同继承 / 覆盖规则：用户明确需求优先，其次是主动自定义的配色与主题，再继承风格和类型规则。默认值不再冒充用户的额外要求；仅打开自定义但未改颜色时继续继承，只改主色时辅色仍跟随预设。复制 Prompt 由后端返回包含风格规范的完整文本。新建重置、历史回填和增量快照同步支持。旧记录中的非默认颜色保留为自定义，旧的独立组件库不再覆盖风格。

## 1. 预览器 (Viewer)

`viewer.html` 是系统的核心交互界面。AI 项目与本地原型统一进入 `.prototype` 工作台，使用相同的三种模式：

| 模式 | 标识颜色 | 功能描述 |
|------|-----------|----------|
| **预览模式** | 🟢 绿色 | 沉浸式预览，隐藏所有侧边栏，模拟真实用户体验 |
| **微调模式** | 🟣 粉色 | 点选 / 框选 / 多选原型元素，复制带稳定锚点与元数据位置的修改 Prompt |
| **标注模式** | 蓝色 | 水滴编号评论、PRD 标注列表与页面需求文档，按 revision 保存 |

AI 项目入口保留旧项目 ID；工作台先将其解析为已登记的 `.prototype` 项目，再复用本地预览、选元和标注界面，不再提供旧编辑 / 研发模式入口。已有 AI 项目的多 HTML 页面与同文件 Vue / Router 状态页保持可导航，已有 PRD 迁入共享元数据时保留已填写的需求。

## 2. 项目管理

首页为全屏项目工作台（2026-10-04），进入后直接显示项目卡片列表，顶部「本地原型 / AI 项目」来源 Tab 与右侧「新建项目」共用一行，点击新建进入独立创建页。首页移除重复的「项目」标题、总数与副文案，数量继续显示在来源页签及搜索结果行。来源默认选中本地原型，选择记忆在浏览器 localStorage，带 `?tab=team` 打开时直达团队页。列表最大宽 1600px，手机自动单列；手机保留完整来源名、数量与新建文案，支持浅 / 深主题切换与键盘操作。

本地页签提供名称 / 路径搜索、全部 / 已连接 / 新发现 / 目录失效筛选，以及「添加本地项目」入口。点击添加展开文件夹选择、路径输入与监视根列表，添加成功后自动收起。AI 项目页签保留我的 / 团队项目、团队选择器、搜索与回收站；项目按创建时间倒序展示。

创建页保留模型、产物类型、设计系统、参考图、PPT 导入 / 逐页描述、页面需求与外部 AI 生成；右侧实时概览显示项目名称、实际页数、参考图数、页面名称与配置。返回项目列表时保留搜索、筛选和草稿，浏览器前进 / 后退支持切换页面；再次点击「新建项目」开始新的草稿。生成提交成功后回到 AI 项目列表显示状态，生成记录中的配置可以回填到创建页继续编辑。

### 创建时填写项目名称（2026-10-04）

设计设置标题下提供可选「项目名称」输入框，最多 80 字。名称行与下方类型 / 风格 / 组件 / 背景筛选共用最大 656px 的宽度，右边缘对齐；窄屏保留两列筛选，手机名称标签上下排列。手动输入去掉首尾空白后优先使用；留空或只输入空白时，按页面名称拼接（以 ` + ` 分隔、最多 80 字）、首个布局描述第一行（最多 24 字）自动命名，均为空时使用「原型项目 MM-DD HH:mm」或「HTML PPT MM-DD HH:mm」。右侧概览实时显示将采用的名称。

AI 生成、复制 Prompt 和 AI IDE 项目包提交前自动填回名称，项目创建请求、生成记录与 Prompt 使用同一名称。返回列表保留名称草稿，再次新建清空；从生成记录回填时优先使用列表中的当前名称，待外部生成的系统后缀不填入名称框，没有列表名称则读取记录名称，兼容无名称的旧记录。仅修改名称不视为增量生成的设计设置改动；异步生成沿用创建时的名称，不由前端读取生成 HTML 的 title 后覆盖。

本地原型卡片操作条（2026-09-26）：预览、**发布 / 导出**、移出列表、删除。「发布 / 导出」打开弹窗——版本二选一（**纯净版**纯 HTML 原型 / **研发版**左侧页面列表 + PRD + 标注气泡评审壳），发布到 GitHub Pages 与本地导出共用该选择；本地导出多页面打 ZIP、单页面纯净版直接下载单个 HTML，研发版始终 ZIP。

AI 项目「导出与分享」复用同一发布 / 导出弹窗和纯净 / 研发版本选择；先解析项目的工作台 ID，再调用共享本地下载与 GitHub Pages 接口。旧 AI 专用导出弹窗及内嵌版本选项移除，团队分享仍使用原团队功能。工作台悬浮菜单的发布与下载也共用所选版本。

AI 两种导出都排除根目录的生成记录、完整 Prompt、TASK / AGENTS / DESIGN、旧 `prd/` 和 `pages/*.md`；保留原型成品与业务资源。研发版使用已迁入工作台的页面需求、标注和图片，不公开生成工程资料。

- 刷新图标（2026-10-05）：本地列表、AI 列表与生成记录的「加载并重新生成」共用同一枚圆头双箭头 SVG，保留原操作、悬停提示、无障碍名称与触屏尺寸。
- 本地项目搜索与排序（2026-10-03）：搜索框按项目名称或路径即时过滤，不区分大小写；已连接和新发现合并按目录创建时间从新到旧排列，卡片状态徽标保留。搜索显示匹配数与无结果状态，清空或按 Esc 恢复全部列表；刷新、切回本地页签及后台重新扫描保留当前搜索内容，旧项目重新连接不跳到顶部。
- viewer 悬浮工具条发布区（2026-09-27）：与首页卡片同一口径的版本二选一（研发版默认/纯净版 segmented），发布到 GitHub Pages 按所选版本提交并显示「已发布（版本）· 时间」；「下载到本地」与发布共用版本选择。发布/下载按钮文案单行显示不折行（2026-09-28：按钮禁折行，面板随内容自适应加宽）。研发版导出物（评审壳）右栏标注序号与操作界面同式、页面序号气泡与预览同式（2026-09-27 三轮统一：序号首行 + 正文另起、水滴 36px 序号气泡、主色 #2563eb），失锚为灰圆 + title 提示（2026-09-28 起失锚收窄为「真失锚」：元素被折叠/隐藏但还在页面上的不再灰显，正常颜色可点击联动展开定位；只有元素真找不到、或可见但落点失效才灰显置底不可点），两边不再维护两套样式。
- GitHub Token 本地持久化（2026-09-27）：token 不再只存于进程环境变量（重启即失），而是落盘 `data/github_token.bin`（已 .gitignore、不入库）；Windows 走 DPAPI 按当前用户账户加密（拷走/异用户无法解密），非 Windows 退化为本机明文文件。环境变量（PROTOTYPE_GITHUB_TOKEN/GITHUB_TOKEN）仍优先用于 CI/临时覆盖；token 仍不写 config.json。发布/取消发布/导出均回退该持久化 token，重启后自动可用。
- 发布菜单与凭据状态（2026-10-05）：配置、发布、下载统一单行图标按钮，菜单宽 240px 且不超出视口；配置按钮缩短为「配置 GitHub Token」。读取失败区分“未配置”和“已保存但无法读取”，缺用户名单独提示；Token 必须成功保存到本地才显示保存成功。Windows 服务应由保存 Token 的同一账户启动，自动化沙箱账户无法解密用户凭据。
- 标注工作台集成微调（2026-09-27）：外部项目（?ext=）除标注外也可用微调（Inspector）——与 AI 项目同一选元交互（悬停高亮/单选/框选/Ctrl 多选），直接复用同一套代码。外部项目的微调“复制 Prompt”沿用与标注修改任务同一套 .prototype 约定（项目/元数据/revision/当前页面文件/选中元素含 data-proto-id/需求），交给 Agent 改真实源文件；“AI 直接修改”仅内部项目适用，外部隐藏。
- 右栏选中态收进首行 + 任务状态自解释（2026-09-27，2026-09-28 改版）：右栏选中标注不再给整块画蓝框，选中信号收进序号与「更多」所在的首行：head 行铺 6px 圆角淡蓝底条（`--ext-soft`），序号加一圈白隙蓝环（与页面气泡 `.pa-selected` 光环同款）；head 负 margin 与 padding 等量，选中/未选中布局不跳。标注正文悬停不画虚线描边（可编辑提示仅保留 cursor: text）；任务状态徽章（待执行/待验证/已验证）悬停有自解释提示。
- 折叠区标注引导与联动展开（2026-09-27，编辑/导出/GitHub Pages 三态一致）：带交互原型交付研发时，对处于折叠区、收起时不可见的标注，在其折叠触发器上盖一层透明呼吸描边框（原型内容透视可见），右上角小标签「展开·N」提示研发此处可点击、内含 N 处隐藏序号（2026-09-28 从实心蓝 pill 改为透明描边框）；点右栏序号时，若目标被折叠隐藏则自动展开对应折叠区（支持原生 details / aria-controls 折叠按钮 / 邻近触发器）再定位。共享能力在 proto-anchors.js（resolveHidden/revealTrigger/reveal），编辑与评审壳均复用。定不到落点的序号（折叠隐藏或失锚）一律隐藏，不再摆成左上角灰色网格；编辑态监听原型 DOM 变动（MutationObserver + transitionend）即时重排，展开/折回多少次引导都能重现；reveal 对同一触发器只点一次，兼容 Vue/React 类延迟更新的原型；隐藏元素文本比对忽略空白（innerText 在隐藏态丢空格）。

### 复制 Prompt 功能

**位置**：创建页顶部的「外部 AI 生成」入口中的「复制 Prompt」选项

**功能**：将设计需求复制到剪贴板，用于 Antigravity、Cursor、Claude 等外部 AI 工具。

**工作流程**：
1. 填写设计需求和上传参考图
2. 点击「复制 Prompt」
3. 自动创建占位项目（状态：待外部生成）
4. Prompt 和参考图已复制/保存
5. 在外部工具中生成 HTML
6. 将 HTML 保存到项目文件夹的 `index.html`
7. 刷新即可预览

### 点击热区提示（2026-10-05）

AI 与本地原型的预览、标注阅读模式中，点击页面空白或手机外的画布空白，当前可见按钮、链接和交互区会以半透明橙色覆盖高亮，18%–42% 不透明度呼吸约 2 秒后自动消失；不带边框、外圈或阴影。没有编号或「展开」文字，区别于隐藏标注的黄色虚线引导。提示层穿透点击，点按钮或链接直接执行原操作；重复点空白不叠加提示或延长计时。

只识别有效跳转链接、实际绑定的点击 / 指针交互、原生选项或表单提交 / 重置等操作；没有事件的静态按钮、空 href / `#` / JavaScript 占位链接、只有 ARIA role 或手形光标的区域不提示。普通 `data-proto-id` 不作为点击依据。模块提前载入，记录 addEventListener 的实际绑定 / 移除，保留 once、capture、signal 和原调用语义；React 根事件代理通过节点上的业务 props 识别。仅由任意祖先代理的自定义操作无法可靠判断目标时，可在真实操作节点声明 `data-proto-hotspot="true"`，排除区域声明 `data-proto-hotspot="false"`。

禁用、隐藏、屏幕外和完全被遮挡的控件不提示；输入、选中文字、拖动、键盘事件、微调、新建标注和正在编辑正文时不触发。减少动态效果时使用 30% 不透明度静态显示约 2 秒。原型源文件不改变，热区识别不自动执行业务操作。

研发版下载与 GitHub Pages 发布内嵌同一提示模块，HTTP 与 file:// 均支持；独立打开研发版中的原型文件不启用评审层，纯净版保持原样。已有静态发布站点需重新发布，才能包含新功能。

### AI 与外部 AI 生成的工作台约定（2026-10-04）

AI 生成、复制 Prompt、AI IDE 项目包共用创建页的工作台约束：根元素声明 `data-proto-page`、`data-proto-state` 与 `data-proto-preview`，交互控件使用页面内唯一、修改时稳定保留的 `data-proto-id`。同一 HTML 的页面或状态切换提供 `PrototypeBridge.enter(stateId)`，业务导航与 `data-proto-state` 双向同步；生成记录保存 `previewType`，移动 App 使用 `mobile`，其他产物使用 `web`。共享工作台可据此进行页面定位、元素标注和后续修改任务。

AI 直生与仅复制 Prompt 保持单 HTML 协议；AI IDE 项目包的文件组织遵循「单文件 / 多文件 / 自动」选择，显式多文件或自动且至少四页使用 `index.html + pages/ + assets/` 协议，避免生成提示词与实际项目包冲突。

AI IDE 包中的 AGENTS / TASK 同步要求稳定锚点、预览类型、幂等异步 Bridge，以及业务 Tab / 路由 / 弹窗与根元素状态同步。同文件页面按名称生成 slug，重复名称依次追加 `-2`、`-3`，default 指向初始视图。

## 3. 团队协作

系统新增轻量级团队协作能力，适合多人共同维护和查看原型项目。

### 账号与会话
- 支持注册、登录、退出登录。
- 登录态通过 `session_token` Cookie 保存，默认有效期 3 天。
- 密码使用 PBKDF2-SHA256 加盐哈希存储，不依赖额外加密库。

### 团队管理
| 功能 | 说明 |
|------|------|
| 创建团队 | 创建者自动成为管理员 |
| 邀请码加入 | 团队生成 8 位邀请码，成员输入邀请码即可加入 |
| 成员列表 | 可查看成员显示名、用户名和角色 |
| 退出团队 | 成员可主动退出团队，空团队会自动删除 |

### 项目分享
1. 登录后创建的项目会记录项目拥有者。
2. 项目拥有者可将项目分享到自己所在的团队。
3. 团队成员可在「团队项目」列表中查看共享项目。
4. 取消分享后，团队项目列表不再展示该项目。
5. 删除项目时会同步清理项目归属和分享记录。

### 数据存储
- 协作数据存储在 `data/collab.db`。
- 使用 SQLite + WAL 模式，支持本地服务的并发读取。
- 旧项目可通过 `python migrate.py <username>` 迁移归属。

## 4. HTML PPT 生成

HTML PPT 是独立产物类型，用于把汇报、方案、课程等内容生成可播放的单文件 HTML 演示稿。

### 输入方式
| 方式 | 说明 |
|------|------|

## 6. 微调模式 (Inspector Mode)

微调模式提供"指哪改哪"的可视化修改能力。

### 交互方式
- **点选**：单击高亮选中单个 DOM 元素。
- **框选**：拖拽绘制矩形框，批量选中区域内元素。
- **追加**：按住 `Ctrl/Cmd` 点击，追加或取消选中。

### 技术原理
1. **覆盖层 (Overlay)**：在 iframe 上方覆盖透明 div (`#inspectorOverlay`) 捕获鼠标事件。
2. **坐标映射**：将主窗口的鼠标/选框坐标转换为 iframe 内部的相对坐标。
3. **元素查找**：使用 `document.elementsFromPoint` 或遍历 DOM 判断矩形相交。
4. **Prompt 生成**：自动提取选中元素的 Tag、CSS Selector 和 HTML 片段。

### API 流程
1. 前端发送 `projectId` + `selector` + `html` + `userRequest` 给后端。
2. 后端 `/api/inspector/apply` 读取当前 HTML。
3. 组装 AI Prompt，调用大模型修改指定元素。
4. 后端备份原文件 (`.bak`)，覆写新 HTML。
5. 前端收到成功响应后刷新 iframe。

### 提示词结构 (2026-02-05 优化)

元素微调提示词现包含以下信息，便于 AI IDE 精确定位：

| 字段 | 说明 |
|------|------|
| 目标文件路径 | 完整绝对路径，可直接打开 |
| 项目ID | 项目文件夹名称 |
| 当前页面 | hash / Vue 路由信息 |
| 元素 CSS 选择器 | 定位元素 |
| 元素 ID/class | 便于搜索 |
| 文本内容 | 前50字符 |
| HTML 片段 | 精确匹配 |

### 整页面修改 (2026-02-05 新增)

底部提示条新增紫色「整页面」按钮：
- 支持针对整个页面的修改需求

### PRD 草稿落库 proto_import.py（2026-09-30）

面向「画原型的 Agent 接着写 PRD」这一步：Agent 根据已有需求和原型，判断哪条该做序号标注、哪条该进页面需求，写成项目根 `.prototype/prd.draft.json`；落库由 [`proto_import.py`](../proto_import.py) 完成，不让 Agent 直接修改 `prd.json`。PRD 内容由 Agent 整理，导入工具负责校验和保存。业务规则不明确时记入 `unknowns`，不要补造；跨会话可用 `.prototype/brief.md` 留下已确认的需求和上下文。协作 skill 可以指导这一步，导入格式与命令以本节和脚本中的示例为准。

- 草稿（schemaVersion 1）：`pages[{file | pageId, stateId?, document?, annotations?[{protoId, body}]}]`。`file` 按登记表 casefold 匹配，`stateId` 默认 `default` 且必须已登记；`unknowns[]` 只回显不落库。

- protoId 解析：扫该页 HTML 的 `data-proto-id`，必须恰好出现一次；缺失或重复默认**整份不落库**并逐条报告，`--skip-missing` 改为跳过问题条。带 `hidden` 属性的元素照常落库，报告里给「提醒」（工作台会显为失锚直到页面让它显现，需要时在工作台重新绑定以记下显现条件）。
- 产物：新标注 anchor `{protoId, selector, tag, text}`，placement `{kind:'element', rx:0, ry:0.5}`（元素左侧中点，可拖），`confirmed:false`，编号接着该页既有标注续；页面文档 `confirmed:false`。同页同状态同 protoId 的标注跳过（重放幂等）；已有正文的页面文档跳过，`--replace-doc` 才覆盖，`confirmed` 文档永不覆盖。
- 落盘：走 `validate_bundle` 后 `save_bundle`，三文件 revision +1；草稿移入 `.prototype/imported/prd.draft.r<rev>.<时间戳>.json` 留档。`--dry-run` 不写标注与文档、不动草稿，但与打开工作台一样会补登记新页面。非 0 退出 = 未落库，stderr 列原因。

## 8. 项目导出

通过 `export_project.py` (或 `导出项目.bat`) 将项目打包。

### 导出模式
1. **纯净版**：原型 HTML 与必要资源，适合演示与体验；单页面可直接下载 HTML，多页面打包 ZIP。
2. **研发版**：只读评审壳、原型副本、页面需求、序号标注与 PRD 图片，适合研发交付；始终打包 ZIP。

### 关键技术：零依赖
导出后的项目**无需 Python 环境**，双击 HTML 即可运行。通过在导出时注入 JS 监听器，解决了 `file://` 协议下的跨域通信问题。
