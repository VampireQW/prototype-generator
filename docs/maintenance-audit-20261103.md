## 结论

可以收掉一整套旧工具入口，而不是只删除几个 bat。当前有效链路是：

```text
启动项目.bat → server.py → src/index.html / src/viewer.html
本地导出 / GitHub 发布 → review_export.py
研发版 → src/review_shell.html + 当前序号、锚点、热区与导航模块
PRD 落库 CLI → proto_import.py
```

旧 `export_project.py` 与现代 `review_export.py` 是两套实现；前者不是当前界面导出功能的依赖。删除“快速恢复”入口也不等于删除备份数据，更不等于移除项目回收站恢复。
