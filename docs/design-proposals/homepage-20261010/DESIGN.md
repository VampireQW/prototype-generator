# 原型生成器首页 UI 设计方案

日期：2026-10-10
状态：历史方案，已于 2026-10-15 被 Vercel 风格产品界面替代。当前有效规范见本项目主 DESIGN.md；本文件仅供回溯。
范围：首页项目工作台及其搜索、筛选、菜单、添加本地项目面板。新建页和预览工作台另按实际改造范围同步。
依据：当前首页实屏、`src/home.css`、`src/index.html`、`src/home-ui.js` 与用户反馈。`finesse-ui` 提供产品界面审查方法，`web-design` 提供规范章节结构；视觉取值在本项目独立定义。

## 1. Visual Theme & Atmosphere｜视觉方向

**方向：冷白画布、石墨导航、冰青强调。**

定位是日常使用的原型项目工作台。首页的主要任务是查找、打开、创建与交付项目。科技感通过冷色材质、清晰的几何轮廓、精确排版与及时反馈体现。

改造前实屏的主要问题：

- 控件普遍采用较明显的描边，背景、卡片和按钮的材质区别不足。
- 项目封面重复使用大图标和圆环，占据较大面积，却不能帮助识别项目。
- 名称、页面数和路径之间的空白偏大，卡片信息重心不集中。
- 卡片底部常用操作与移出、删除并列，操作层级缺少区别。

新方案形成三个明确的视觉层次：深石墨顶栏、冷白项目画布、清晰的项目内容卡片。品牌用冰青色点缀，主操作使用同色相的深青色保证文字可读性。浅色为初始建议，保留已有浅深外观选择与用户偏好。

首页信息结构保持全屏项目库。本地原型 / AI 项目页签与新建项目同排。交互采用 L1 精致静态档位，以 CSS 状态反馈为主。

图片位置：仅项目卡片封面，来自项目真实首屏缩略图，随项目数量变化。封面由 home_thumbnails.py 异步生成、缓存复用，加载不阻塞项目名称和操作。没有缩略图时显示项目名称缩写、类型和已有统一图标构成的身份封面，明确作为未生成封面。

与现有界面的差异落在配色、材质、卡片信息组织和内容封面上，项目库导航仍遵循用户已明确的工作方式。

## 3. Typography Rules｜排版

沿用中文优先的系统字体，首屏无需远程字体请求：`"PingFang SC", "Microsoft YaHei UI", "Microsoft YaHei", "Noto Sans CJK SC", system-ui, sans-serif`。路径采用 `"Cascadia Code", Consolas, monospace`。不另引入字体下载依赖。

| 角色 | 字号 / 行高 | 字重 | 规则 |
|---|---|---|---|
| 品牌名称 | 18 / 28px | 650 | 顶栏一行 |
| 来源页签 | 14 / 22px | 500，选中 600 | 计数使用等宽数字 |
| 项目名称 | 16 / 24px | 600 | 最多两行，相同卡片名称区域对齐 |
| 按钮与输入 | 14 / 22px | 500 / 400 | 按钮文案不折行，输入左对齐 |
| 普通说明 | 15 / 25.5px | 400 | 只在必要时出现 |
| 页面数、日期、状态 | 12 / 20px | 400 / 500 | 保持可读，不使用低对比度浅灰 |
| 文件路径 | 12 / 20px | 400 | 单行截断，悬停或聚焦可查看完整路径 |

信息层级由字号、字重、位置和颜色共同建立。项目名称为卡片主信息，路径为次信息。页面不添加重复的“项目”标题与说明，也不使用装饰性英文标语。

## 4. Component Stylings｜组件体系

### 尺度与材质

- 普通按钮、搜索框、筛选器圆角 10px；项目卡片 14px；菜单与添加面板 16px。尺寸按组件角色取值。
- 品牌标识沿用现有图形，以冰青配石墨底调整表现。
- 搜索和筛选使用浅色内凹底，默认边界轻；交互区域仍有足够的形状与对比度。
- 常用图标复用首页同一套 SVG，图标 18px，视线中心和线宽统一。本地与 AI 卡片共用相同操作组件。

### 按钮、页签与输入状态

| 控件 | 默认 | Hover | Active / 选中 | Focus | Disabled / Loading |
|---|---|---|---|---|---|
| 新建项目 | 深青实底、浅色文字 | 加深底色 | 更深底色、轻按压反馈 | 清晰外圈 | 禁用灰底；提交显示进度并防止重复操作 |
| 添加本地项目 | 浅青填充、深色图文 | 填充加深 | 稍深填充 | 清晰外圈 | 禁用仍能辨认文案 |
| 图标按钮 | 无显著边框，36px 点击区 | 出现浅底 | 底色加深 | 键盘外圈、显示提示 | 无点击效果，解释不可用原因 |
| 来源页签 | 轻量分段底板 | 标签底色反馈 | 选中项实色底片、字重提高 | 键盘外圈，方向键切换 | 数据载入与失败分别表达 |
| 搜索 / 筛选 | 浅色填充、轻边界 | 边界提高 | 输入仍左对齐 | 输入聚焦边界清晰；键盘焦点完整 | 错误反馈就近显示；不清空已有输入 |

鼠标操作无需额外的选中框，键盘操作保留明显焦点。图标按钮具有可访问名称与原生悬停提示；触屏扩大至至少 44px 点击区。

### 项目卡片

卡片结构：**项目内容封面 → 名称 → 页面数与日期 → 路径或来源信息 → 操作**。

- 封面采用约 2:1 的内容窗口；真实截图保留项目颜色与布局，并适当缩放留出观看边距。App 封面在同一窗口内居中展示手机内容。
- 状态标签固定在封面右上角，用轻量底色配文字。“已连接”“新发现”“目录失效”等现有语义保持准确。
- 名称、元信息与路径间距控制在 6–8px，不因名称短而产生大块空白。卡片默认目标高度约 250–280px。
- 卡片表面以填充与浅阴影建立层次，默认边框轻；Hover 提高表面和阴影层级，上移最多 2px，不缩放截图。
- 主卡片点击打开项目。独立操作区避免嵌套按钮、阻止操作冒泡；键盘能分别访问打开、预览、交付和更多。
- 底部默认显示预览、发布 / 导出和更多图标，不带常驻文案。移出、删除进入更多菜单，菜单明确区分“移出列表”和“删除本地文件”。删除确认展示项目名和影响范围。
- 新发现项目的连接操作使用已有统一连接图标，状态处理中防止重复提交；连接成功后就地更新。
- 卡片激活、键盘聚焦、不可用、加载中都有明确状态。目录失效时提供添加新目录的入口，旧登记可单独移出。

### 菜单与添加面板

- 下拉箭头与右缘间距 12px，菜单项高度 36px，触屏 44px。选中项有勾选和浅底。
- 添加本地项目在触发按钮附近展开统一面板；标题、关闭按钮、选择文件夹与粘贴路径具有稳定对齐。
- 目录结果按紧凑条目显示，移除叉号紧邻条目，不推至屏幕边缘。路径校验信息跟随输入显示。
- 菜单支持 Esc、外部点击关闭及焦点返回；面板提交期间防止重复操作。错误后保留路径与结果。

## 5. Layout Principles｜布局

结构示意：

```text
┌────────────────────────────────────────────────────────────────────┐
│ 原型生成器                              模型设置   外观   用户菜单 │ 56px
├────────────────────────────────────────────────────────────────────┤
│ [本地原型 40] [AI 项目]                                  ＋新建项目 │
│ 搜索项目名称或路径    全部项目       项目数 / 最近创建   添加项目 ↻ │
│                                                                    │
│ [项目内容封面] [项目内容封面] [项目内容封面] [项目内容封面]          │
│  名称 / 元信息  名称 / 元信息  名称 / 元信息  名称 / 元信息           │
│  图标操作       图标操作       图标操作       图标操作                │
│                                                                    │
│ [项目内容封面] [项目内容封面] [项目内容封面] [项目内容封面]          │
└────────────────────────────────────────────────────────────────────┘
```

- 顶栏 56px，品牌与全局配置分离；顶栏背景为石墨色，首页内容保持浅色画布。
- 主内容最大宽度 1760px，桌面边距 32–48px，距顶栏 16px。
- 来源与新建同行，分段页签外框 44px；搜索工具行 40px，来源行下间距 12px。
- 项目数与“最近创建”合入工具行或紧邻工具行的紧凑辅助区，避免独占宽松的一行。
- 1440px 参考视口以 4 列为目标，1920px 以 5 列为目标；实际按可用内容宽度与约 260px 最小卡宽自适应。
- 卡片横向间距 20px、纵向 24px；第一排在 1440 × 900 参考视口约距顶端 180–200px 出现。
- 默认最新创建优先；刷新、切换来源与返回列表保留合理的搜索、筛选及滚动位置。

## 6. Depth & Elevation｜层次

```css
:root {
  --home-card-shadow: 0 2px 8px rgba(23, 33, 44, .045);
  --home-hover-shadow: 0 8px 24px rgba(23, 33, 44, .10);
  --home-popup-shadow: 0 16px 48px rgba(23, 33, 44, .16);
}
:root[data-home-theme="dark"] {
  --home-card-shadow: 0 2px 8px rgba(3, 10, 18, .20);
  --home-hover-shadow: 0 8px 24px rgba(3, 10, 18, .30);
  --home-popup-shadow: 0 16px 48px rgba(3, 10, 18, .42);
}
```

普通卡片、Hover、浮层使用三个固定层级。仅菜单和弹层需要较强阴影；项目内容区保持清晰。图标线条承担图形表达，控件无需普遍采用粗描边。

## 7. Animation & Interaction｜反馈与完整状态

动效以状态反馈为主：按钮 120–160ms，卡片 160–200ms，菜单 140–180ms。初次列表可做一次 120ms 淡入；搜索和刷新直接更新结果。减少动态效果时取消位移和入场。

| 情境 | 反馈与下一步 |
|---|---|
| 首次读取 | 展示与最终卡片相同尺寸的骨架，保持网格位置 |
| 手动刷新 | 保留已有项目，刷新按钮显示处理中；失败保留旧结果并允许重试 |
| 没有项目 | 区分本地与 AI，提供添加本地项目或新建项目入口 |
| 搜索无结果 | 显示当前条件，提供清除搜索 / 筛选 |
| 数据读取失败 | 明确原因和重试操作，不显示假数量或假成功 |
| AI 项目需要登录 | 就近说明并提供登录入口，本地列表继续可用 |
| 单个项目失效 | 卡片状态与添加新目录入口，其他卡片继续可用 |
| 连接 / 导出处理中 | 独立显示当前操作进度，阻止重复提交，成功后更新对应项目 |
| 长名称 / 特殊路径 | 文本可截断但完整信息可查看，布局不被撑开 |

商业 UI 验收应覆盖 default、hover、active、selected、focus、disabled、loading、error，而非仅检查静态首页。键盘操作贯穿页签、筛选、卡片、菜单和弹层。

## 8. Do's and Don'ts｜设计约束与实施范围

### 必须做到

1. 配色、圆角、阴影、尺寸按本项目语义 token 统一。
2. 本地与 AI 使用相同卡片骨架、操作图标和反馈方式。
3. 项目名称、状态和真实内容封面是主要识别信息。
4. 状态文字与图标一起表达结果，提交和错误反馈真实。
5. 既有搜索、最新创建排序、连接、预览、导出和分享流程均能完成。
6. 对应组件在浅深主题、键盘和触屏下具备完整状态。

### 避免

1. 全页反复使用明显边框作为主要层级手段。
2. 每张卡片重复相同的大图标与装饰圆环。
3. 大型欢迎区、宣传文案或无业务依据的统计卡占据首屏。
4. 用隐藏常用操作来维持截图整洁；触屏用户尤其需要可见入口。
5. 删除本地文件与打开、预览并列成为普通卡片操作。
6. 用几十个实时 iframe 生成列表封面。
7. 搜索、排序和刷新时重置整个画布或播放长入场动画。
8. 科技风格的装饰影响文字识别、输入和滚动效率。

实施涉及 `src/home.css`、首页结构、卡片渲染与菜单组件；共用首页控件需检查新建页的显示，避免主题切换后出现旧色块。真实缩略图属于新增能力，应异步生成、缓存复用、限制并发，并按需加载。首页先呈现项目文字信息，封面在后台更新。

本方案只约束原型生成器自身界面；生成出的原型继续遵循各项目选择的风格。项目主 DESIGN.md、功能、接口、架构和变更日志同步维护当前实现。

## 9. Responsive Behavior｜适配与交付验收

| 宽度 | 布局与交互 |
|---|---|
| ≥1600px | 通常 5 列，内容保持最大宽度约束 |
| 1200–1599px | 通常 4 列，桌面间距 |
| 900–1199px | 通常 3 列，工具行按需换行 |
| 641–899px | 通常 2 列，搜索区域优先宽度 |
| ≤640px | 1 列；搜索全宽，筛选、添加和刷新在同一工具行，触摸目标至少 44px |

具体列数以可用宽度为准，不强塞窄卡。320px 宽仍能完成搜索、打开、添加和菜单操作。长按钮文案不折行；需要时整项换到下一行。

交付前验证：

- 1440 × 900、1920 × 1080、900px、375px、320px 及浅深两种主题的实屏。
- 中文、长名称、英文与 Windows 路径，无裁字、错位和横向溢出。
- 来源切换、搜索、筛选、排序、添加、连接、打开、预览、发布 / 导出以及更多菜单的实际操作。
- 加载、空结果、读取错误、未登录、目录失效与重复提交。
- 键盘焦点、Esc 关闭、焦点返回、触屏点击和减少动态效果。
- 新主题下全局菜单、添加面板与共用新建页组件的一致性。
- 首屏文字不被缩略图加载阻塞；封面缺失、失败或更新不造成列表跳动。

实屏验证覆盖 320 / 375 / 900 / 1440 / 1920px，浅深主题、搜索、菜单键盘操作、新建页与发布弹窗；接口和渲染使用隔离项目验证。未向真实 AI 服务提交生成，未执行真实 GitHub 发布或项目删除。
